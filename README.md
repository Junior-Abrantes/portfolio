# Portfólio · Junior Abrantes

Site pessoal publicado em **portfolio.cattleyatech.shop**.

Página única em HTML, CSS e JavaScript puros, sem build: hero com campo gerativo em canvas,
navegação em pílula que se compacta ao rolar, revelação de texto por palavra, contadores,
acordeões e modais de projeto.

Logos e retrato são servidos de `cattleyatech.shop`.

Deploy: Vercel, projeto `portfolio` (time cattleya), sem framework.
